## Overview

Baby Audio Tekno generates rhythmic gating, pumping, and sidechain compression effects synchronized to the DAW tempo, essential for trance, techno, and electronic music production.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Baby Audio Tekno** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Trance Gate** | Pattern-based amplitude sequencer synchronized to BPM |
| **Pump Mode** | Sidechain compressor emulation with adjustable attack and release |
| **Pattern Editor** | 16-step gate pattern editor with velocity and swing per step |
| **Stereo Spread** | Independent left/right gating for wide rhythmic stereo effects |
